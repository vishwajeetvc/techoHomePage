# Blogging Website 📝

A fully responsive blogging website built with **React**, **Tailwind CSS**, and **React Router**.  
This project features a clean and modern UI, smooth navigation, and a mobile-first design approach.

![App Screenshot](./m24home.png)

---

## 🚀 Features
- 📱 Fully responsive design (mobile, tablet, desktop)  
- ⚡ Built with **React + Tailwind CSS**  
- 🔗 Navigation powered by **React Router**  
- 🎨 Minimal and modern UI for a better reading experience  

---

## 🛠️ Tech Stack
- **React.js**  
- **Tailwind CSS**  
- **React Router DOM**
